# ============================================================================
#  FOWL AND FURIOUS — the title theme.  Edit freely, then run make.
#
#      tempo N        frames per beat. At 50 Hz, 9 is a brisk 333 bpm quaver
#                     feel; raise it to slow the whole tune down.
#      melody / bass  then NAME LENGTH pairs, lengths in beats.
#                     Names are C4, F#3, A5 and so on; '-' is a rest.
#
#  There is no music player in the game. Each note becomes one step of the
#  same six-byte format the sound effects use, so the tune is just a very
#  long "sound" — see tools/music.py. That means a note cannot bend or
#  swell mid-way, but it also means fifteen seconds of theme cost no code.
#
#  Melody plays on channel A, bass on channel B. Channel C is left for the
#  effects, though nothing squeals on the title screen.
# ============================================================================
